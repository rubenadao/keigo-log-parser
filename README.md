# keigo-log-parser

Parses RocksDB visual profiler logs into JSON for the Keigo visualizer.

## Usage

Point it at a run directory with a `manifest.yaml` and it figures out the rest:

```bash
pip install -e .
keigo-parser quick ~/runs/my_experiment/ -o output.json
```

Works with directories generated by `run_bench.sh` or any directory containing:
- `manifest.yaml` - run metadata and file locations
- `visual_profile.log` - trace data from RocksDB visual profiler
- `output.log` - db_bench output (optional, for performance data)

## Options

```bash
keigo-parser quick <dir> -o trace.json         # specify output path
keigo-parser quick <dir> -o trace.json -c rocksdb   # use a config
```

## Configs

Configs customize parsing for different storage engines or visualization preferences.

See available configs:
```bash
keigo-parser configs
```

Built-in: `rocksdb`, `rocksdb-tiered`, `wiredtiger`, `leveldb`, `postgres`, `single-phase`
